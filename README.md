# Coil-beregner

En lille web-app til at finde den bedste kombination af coils (kg) til et ønsket kg-mål,
tilføje parti nr. til de valgte coils, og gemme en A4-oversigt som PDF.

## Sådan bruges den
Åbn `index.html` i en browser, eller besøg GitHub Pages-linket når den er sat op
(Settings → Pages i dette repo).

## Filer
- `index.html` – selve appen
- `manifest.json` – gør det muligt at "Føj til startskærm" på Android/iOS som en rigtig app
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` – app-ikoner
- `apple-touch-icon.png`, `favicon.ico`, `favicon-32.png` – ikoner til browser/iOS
